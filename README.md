# Speed Auto Car - SpeedExport.pro

Web portal for importing Korean and Chinese cars to Algeria.

## Features & Integrations
- **Meta Pixel & Conversions API (CAPI)**: Integrated tracking for PageView, ViewContent, AddToCart, Contact, and direct Purchase conversion triggered on "إتصل بنا مباشرة".
- **TikTok Pixel**: Integrated event tracking for advertising campaigns with Purchase conversion on direct call button.
- **Cloudflare Pages Serverless Proxy**: Serverless CAPI function at `/functions/api/meta-events.ts`.
- **Firebase Firestore**: Dynamic real-time pixel management and catalog management.
